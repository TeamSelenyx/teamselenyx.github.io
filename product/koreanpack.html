상품 설명

Minecraft의 잘못된 한국어 번역들을 올바른 번역으로 수정해주고, 새롭게 추가된 아이템이나 블록의 번역을 미리 추가하여 플레이할 때 불편함이 없도록 해주는 리소스 팩 입니다.

주요 특징

  • Ore UI 대응: 기본 번역은 물론, Ore UI 부분도 지원하여 다양한 환경에서 올바른 번역을 확인할 수 있습니다.
  • Vanilla 기반: 원래 언어 파일을 기준으로 수정 사항들을 적용하여 누락되는 번역 없이 수정하여 배포합니다.
  • 지속적인 업데이트: 새로운 Minecraft 버전이 업데이트 될 때마다 지속적으로 수정하고 업데이트하여 배포하고 있습니다.

추천 사항

Plus 버전으로 다운로드 시 Vanilla 버전과 Ore UI 버전이 통합된 버전으로 다운로드 하실 수 있습니다.
